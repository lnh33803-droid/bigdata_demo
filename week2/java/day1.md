“helloworld”的案例（发现有些在idea可以简写的内容，在Linux上并不兼容，无敌了）
    package com.linhan.test;
        //package：当前的类定义在哪个包下，包名建议和公司域名反向
        //idea自动生成
    public class helloworld
{
        //定义一个类
        //class：定义一个类，类是java项目中最基本的组成单元
        //public：访问修饰符，表示这个类可以被其他包访问
        //helloworld：类名，建议每个单词的首字母大写，不使用下划线和连接符
        //{}:类的范围，代码要写在大括号中
    public static void main(String[] args)
        //表示java程序的主入口，当程序开始运行时，会从主入口开始逐行往下运行
    {
        //输出语句，打印语句
    System.out.println("hello world");
        //输出一段文本：文本内容hello world
        //如果要修改文本内容，修改双引号之间的文本

        /*注释快捷键
            单行：Ctrl + /
            多行：选中文本后，Ctrl + Shift + /
            注释不会影响运行结果，仅仅说明代码的用途
            注释最好别嵌套
         */
    }
}
