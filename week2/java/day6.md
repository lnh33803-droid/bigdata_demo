    2.原码 反码 补码
       
      原码：数据在计算机转换为二进制的编码
            8个bit，1个字节   最左边的bit是符号位，0表示正数，1表示负数     
            最大值：01111111（127）
            最小值：11111111（-127）

      反码：为了便于计算将原码做调整
           计算规则：正数的反码就是其原码;
           负数的反码是其原码除符号位外取反，0->1，1->0
           -56原码：10111000  反码：11000111

      补码：（-128-127）为了解决反码计算跨零时会产生误差
           计算机的存储和计算都是用补码
           符号位不变，其他位取反加1；即反码加1
           例如：-56的补码：11000111 + 1 = 11001000


         byte 一个字节（就可以理解为什么byte的范围是-128到127）
         short 两个字节
         int 四个字节
         long 八个字节

         隐式转换：
           eg：byte -> int 在前面补零
         强制转换：
           eg：int -> byte 去掉3个字节
